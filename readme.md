# 🎧 Beats Landing Page

A modern and responsive **Beats headphones landing page** built using **HTML5** and **CSS3**.
This project replicates a real-world product landing page design and is perfect for practicing **UI layout, responsiveness, and clean CSS architecture**.

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **Google Fonts (Poppins)**
* **Font Awesome Icons**
* **Responsive Design (Media Queries)**

---

## ✨ Features

* Responsive navigation bar with mobile menu icon
* Product hero section with pricing & CTA
* Brand stats section (Apple, Spotify, Amazon, YouTube)
* Specifications section with icons
* Product case & banner section
* Product cards with pricing
* Fully styled footer with social icons
* Dark-themed modern UI

---

## 📱 Responsive Design

The website is fully responsive and adapts to:

* Desktop 💻
* Tablet 📱
* Mobile 📲

Achieved using **CSS Flexbox** and **media queries**.
